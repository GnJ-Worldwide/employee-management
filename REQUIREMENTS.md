## ABOUT PROJECT
This is a contractor/field workforce management system — likely used by a company that deploys workers to construction or service sites. It manages employees, work orders, attendance, billing, and document downloads — all from a centralized web portal.

There will be a Superadmin role
superadmin can create subadmins, hr, employee
each role will have access to different modules/panel

NOTE: this Admin Module is different from the actual admin user ! 
this admin module is used for the business logic purposes
